# RAGFlow 知识库管理页面

入口：**知识中心 → RAGFlow** 管理连接配置，或 **新建知识库 → RAGFlow** 接入知识库。已有 RAGFlow 知识库自动打开专用管理页；其他检索引擎保留原页面。

## 接入与权限

1. 管理员保存服务地址及 API Key。留空保留现有密钥，填写新值进行轮换；页面不会回填已保存的密钥，也不将凭据写入浏览器存储。
2. 运行连接检测。健康、认证和 API 契约分别展示；无法确认服务版本时显示 `version_unknown`，不将契约检测当作模型或解析验收。
3. 创建托管数据集，或分页选择已有数据集进行接入。附加默认只读；只有显式选择管理模式才可修改远端文档。新接入文档默认草稿，不自动发布。
4. `202` 仅表示请求受理，可以进入知识库查看操作记录；仅核验完成的操作显示成功。

权限来自服务端 `GET /api/v1/knowledge/{kb_ref}/ragflow/binding` 的 `can_manage`、`can_write`、`can_reconcile`。页面用不可变知识库 ID 路由，重名的旧名称链接不自动选择其他知识库。共享只读授权不提供管理功能。

## 文档与知识生命周期

- 上传文件或新建空白文档；远端网页抓取尚未开放。
- 搜索、分页查看文档，下载原件，编辑名称、元数据和解析配置。
- 启动/取消解析。重建有片段的文档需要明确确认；文档的 Ingestion Pipeline 选项必须与实际配置相符。
- 查看、创建、编辑、删除 Chunk，调整可用性、关键词、问题和标签。
- 显式发布、撤回草稿、停用和归档。解析/编辑后须检查内容并重新发布；发布使用版本校验，冲突后需刷新。
- 普通检索仅包含已发布文档；检索测试可以显式选择当前页文档进行草稿预览，预览不改变发布范围。
- 查看操作记录与事件。结果未知时先核验，不自动重复远端写请求；运行中状态进行读轮询，终态停止。

## 删除边界

解除本地连接不删除 RAGFlow 数据；整库远端删除仅向托管且可写的知识库提供，并要求输入名称确认。删除文档、Chunk 或整库的远端内容不等于移入本地回收站，界面会说明影响。

## 验证边界

自动测试与浏览器模拟响应验证前端交互和接口契约，不证明实际 RAGFlow 服务部署、模型配置、真实文件解析或检索质量。生产验收仍需有效服务端连接，在测试知识库上完成上传 → 解析 → Chunk 核对 → 发布 → 检索 → 下架的真实闭环。

代码入口：`web/lib/ragflow-api.ts`、`web/components/knowledge/ragflow/`。具体测试结果见 [VERIFICATION.md](VERIFICATION.md)。
