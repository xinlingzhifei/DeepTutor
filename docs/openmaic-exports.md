# OpenMAIC 导出与验收

导出从 yFeiSTAI 页面发起，使用已保存的课堂文档和受控媒体清单。下载地址由
yFeiSTAI 提供；浏览器不直接访问 OpenMAIC 或渲染容器。MP4 按租户策略启用，
读取策略失败时保持禁用。

## 当前输出

- `classroom_zip`：课堂 JSON 和清单内媒体，保留可移植课堂数据。
- `pptx`：可编辑的课堂文字、PowerPoint 原生公式和受控图片；含公式的页面保留
  文字与公式的相对位置，互动和 PBL 场景使用静态说明。
- `offline_html`：内联媒体、可翻页内容和浏览器原生 MathML 公式，不依赖公网资源。
- `mp4`：通过私网渲染服务生成 H.264 静音课件，当前每页展示 30 秒。
  此输出不代表带配音、交互或完整课堂动作的回放。

## 渲染服务接线

固定版本的 `openmaic-render` 使用原生接口：

1. `POST /render` 提交 multipart 表单；`project` 是包含 `index.html` 和全部
   内联资源的 ZIP，另带 `fps`、`quality`、`format`。
2. `GET /render/{jobId}` 查询状态。
3. `GET /render/{jobId}/download` 下载成功产物。
4. `DELETE /render/{jobId}` 取消任务。

租户鉴权、策略和任务归属由 yFeiSTAI 与 OpenMAIC 的签名服务边界检查。
原生渲染接口仅在内部网络访问，保留容器的出站隔离；不能开放为公网入口。
Compose 为渲染容器设置 `HOME=/app`，使降权后的 Chromium 能使用可写目录。
容器健康检查成功并不能证明浏览器可以启动。

## 验收要求

以同一已部署版本完成资料上传、大纲生成、页面确认、内容生成和四种导出，
并保存各阶段的任务标识、响应状态和产物摘要。密钥和会话不得写入验收记录。

- ZIP 检查 CRC、成员路径、课堂 JSON 和媒体清单的一致性。
- PPTX 检查实际打开、页数、可编辑文字和公式内容；仅检查 ZIP 文件头不够。
- HTML 在断网浏览器中打开，核对正文、公式、翻页和脚本错误。
- MP4 完整解码，核对分辨率、时长及不同页面的画面。逐帧定位必须直接驱动
  GSAP 属性，不能依赖会被渲染器屏蔽的回调事件。

本地测试或隔离渲染结果不能替代上述已部署版本的完整验收。
