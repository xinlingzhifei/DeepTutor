# OpenMAIC 共享课程模型配置

管理员在“模型设置”中选中的默认大模型是共享课程生成的配置来源。保存、应用或完成首次设置后，后端自动同步 API 地址、模型名和凭据；无需操作员再填写模型文件路径或重启 OpenMAIC。普通用户、个人 OAuth 与租户专属配置不覆盖共享模型。

## 启动与使用

1. 运行 `scripts/init_platform_secrets.py` 初始化服务密钥和共享模型目录，核验服务密钥的实际权限。模型尚未配置时允许启动 OpenMAIC、执行共享数据面登记与部署检查；数据库、存储、服务鉴权、Observer、HTTPS 等原有门禁仍须通过。
2. 管理员进入页面选择默认大模型并保存。页面提示同步成功后，后续课程生成请求读取新配置。
3. 清空选择或移除必需的 API Key 后，共享生成返回“请管理员先配置模型”。健康检查、现有课程读取和导出不因缺少模型而被停用。
4. 同步失败时页面提示失败，修正配置后重新应用。API 重启也会从已保存的管理员目录恢复同步。

目前自动同步支持页面提供的 OpenAI Chat Completions 兼容接口和 Anthropic 接口，包括自定义接口；API 地址保持页面配置。个人 OAuth、Azure 专有接口，以及带额外请求头或 API 版本选项的配置会明确报告不支持，不会静默换用其他人的凭据。无鉴权本地 OpenAI 兼容服务使用固定的非秘密占位 token。

## 部署接线

共享文件 `data/system/secrets/openmaic-providers/shared/providers/platform-default` 是后台生成的受保护投影，不再是部署时必须手工提供的输入。共享叶目录只含共享模型：yFeiSTAI 可写，OpenMAIC 和 bootstrap 只读；租户目录没有挂入共享服务。目录挂载保证原子替换后的新文件对容器可见。生产文件为 UID/GID `1000:1000`、权限 `0600`。

后台用 PostgreSQL 会话锁串行同步，先持久化未配置状态，再提交共享模型元数据，最后原子发布新凭据；故障时不继续使用旧凭据。模型实例在每个生成请求开始时读取一次。切换期间已排队任务仍受现有路由摘要校验约束，不绕过任务绑定检查。

OpenMAIC 共享目录可以为空；专属租户仍保留原单文件配置和严格启动校验。旧版本部署计划中“共享 OpenMAIC 缺模型则拒绝启动”和“手工准备共享模型文件”的描述由本说明替代。

本次源码变更必须随新的 yFeiSTAI 和 OpenMAIC 镜像、Compose 发布包一起发布。旧候选 `yfeistai-first-release-20260908-92ef9fa8` 及其已预拉镜像不包含该功能，不应修改其镜像锁或原地拼接覆盖文件来宣称发布完成。
